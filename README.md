## 🗂️ Repository Structure

The repository is structured with a flat hierarchy where each problem has its own dedicated folder named in `kebab-case`. 

Inside each folder, you will find the solution files. I use a `submission-X` naming convention to keep track of different approaches, optimizations, or attempts for the same problem. This structure also easily supports adding solutions in different languages in the future.
